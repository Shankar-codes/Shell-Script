# 🐚 Shell Script Collection

This repository contains a collection of basic to intermediate **Shell Scripts** designed for learning, automation, and DevOps practice.

## 📌 Overview

This project is a hands-on collection of shell scripting examples that demonstrate:

- Basic shell commands
- Script execution
- Variables and arguments
- Conditional statements
- Loops and automation
- Real-world scripting use cases

Shell scripts are widely used to automate tasks in Linux environments, making them essential for DevOps and system administration.
